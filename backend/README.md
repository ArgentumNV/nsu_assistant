# NSU Assistant Backend

Запуск: `go run ./cmd/server` (порт 8080). Проверка: `go test ./...`.

## Расписание ИИР

`GET /api/v1/groups` — список групп Института интеллектуальной робототехники:

```json
{"groups":["24943","25940","26940"]}
```

Список выше — пример; фактические группы загружаются с https://table.nsu.ru/faculty/iir,
повторы удаляются, группы сортируются. Для выбора группы на фронтенде используйте этот endpoint.

`GET /api/v1/schedule?group=24943&date=2026-10-19` — занятия выбранной группы на дату:

```json
{
  "group": "24943",
  "date": "2026-10-19",
  "lessons": [
    {
      "subject": "Разработка программных продуктов на базе ИИ технологий (лекция)",
      "start_time": "10:50",
      "end_time": "12:25",
      "room": "412 КПА"
    }
  ]
}
```

Ответ выше сокращён. Дата передаётся в формате `YYYY-MM-DD`, время — новосибирское.
Сервис проверяет принадлежность группы к ИИР, затем читает официальный экспорт
`https://table.nsu.ru/ics/group/{group}`. HTML таблицы занятий не разбирается.
Учитываются даты начала и окончания повторений, интервал недель, исключения EXDATE
и дополнительные даты RDATE. Предмет сохраняется вместе с типом занятия из SUMMARY;
параллельные занятия возвращаются отдельными элементами. Выбор конкретной подгруппы
не предусмотрен. Данные отражают экспорт сайта, включая его возможные неточности.
В выходные и вне дат расписания возвращается `"lessons": []`.

Ошибки: `400` — отсутствует группа или некорректная дата, `404` — группа не найдена
среди групп ИИР, `405` — метод кроме GET, `502` — источник недоступен или вернул
некорректные данные. HTTP-запросы имеют таймаут 15 секунд и используют контекст запроса.

Тесты используют сохранённый ICS НГУ и локальный HTTP-сервер, внешний доступ им не нужен.
